# Little Lemon Restaurant Reservation App 🍋

This is the Capstone Project for the Meta Front-End Developer Professional Certificate. It is a responsive web application that allows users to reserve a table at the Little Lemon restaurant.

## 🚀 Features

- **Responsive Design:** Works on mobile, tablet, and desktop.
- **Form Validation:** Prevents invalid dates and ensures required fields are filled (HTML5 & React state validation).
- **Unit Testing:** Includes tests for component rendering and state management functions using Jest and React Testing Library.
- **Accessibility (a11y):** Semantic HTML tags and ARIA labels for screen readers.
- **API Integration:** Simulates fetching available times and submitting booking data using a mock API.
- **State Management:** Uses `useReducer` and `useState` to manage application state efficiently.

## 🛠️ Technologies Used

- React.js
- React Router DOM
- CSS3 (Grid & Flexbox)
- Jest & React Testing Library
- Semantic HTML5
