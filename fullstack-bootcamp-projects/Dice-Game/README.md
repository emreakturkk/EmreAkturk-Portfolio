# 🎲 Dice Game Challenge 2.0

An interactive web application that simulates a dice roll between two players. This project demonstrates **DOM Manipulation**, **Event Handling**, and **CSS3 Animations**.

### 🚀 New Features (v2.0)
Unlike the basic static version, this upgraded version includes:
* **Interactive "Roll" Button:** No need to refresh the page manually.
* **Shake Animation:** CSS keyframes add a realistic shaking effect before the result.
* **Dynamic Logic:** JavaScript calculates the winner instantly after the animation.

---

### 🛠️ Technologies Used
* **JavaScript (ES6):** Logic for random number generation and DOM updates.
* **CSS3:** Flexbox layout and `@keyframes` for the shake animation.
* **HTML5:** Semantic structure.

---

### 📸 How It Works
1.  Click the **"Roll the Dice!"** button.
2.  Watch the dice shake! 🎲
3.  See who wins (Player 1, Player 2, or Draw).
